Este repositorio compila el desarrollo práctico y los diseños arquitectónicos implementados en Oracle Database para el curso de Tópicos Avanzados de Datos. Incluye la modularización de lógica de negocio compleja con paquetes en PL/SQL, sintonización de rendimiento utilizando el Optimizador Basado en Costos (CBO), políticas forenses de seguridad y auditoría, planes de respaldo y recuperación mediante RMAN, y soluciones de continuidad de negocio con Active Data Guard.
